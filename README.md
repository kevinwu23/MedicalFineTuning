## Overview

This project provides standardized datasets for training and evaluating language models on medical domain knowledge. The datasets cover various medical areas including clinical notes, drug approvals, and medical guidelines.

## Data Structure

The `data/datasets` directory contains CSV files for each of the training and evaluation datasets:

```
data/
├── datasets/
│   ├── medical_notes.csv
│   ├── drug_approvals.csv
│   └── medical_guidelines.csv
```

Each dataset follows a consistent format with the following key columns:

- **input**: The prompt containing the question or instruction given to the model
- **answer**: The ground truth answer for evaluation
- **model_response**: The response generated by a specific model (for evaluation datasets)

## Dataset Descriptions

### Medical Notes

This dataset contains questions about patient medical notes, testing a model's ability to extract and reason about clinical information.

### Drug Approvals

This dataset focuses on pharmaceutical regulatory knowledge, with questions about drug approvals, dosing, indications, and contraindications.

### Medical Guidelines

This dataset tests knowledge of medical guidelines and best practices across various medical specialties.

## Usage

### Loading Datasets

You can load the datasets using the provided `Dataset` class:

```python
from data.dataset import Dataset, MedicalNotesDataset, DrugApprovalsDataset

# Load a general dataset
dataset = Dataset("medical_guidelines")
df = dataset.get_dataframe()

# Load a specialized dataset
med_notes = MedicalNotesDataset("medical_notes")
```

### Fine-tuning

To generate fine-tuning data in JSONL format:

```python
dataset = Dataset("medical_guidelines")
df = dataset.get_data_split(split="train")
dataset.generate_finetuning_data(df, "finetune_data.jsonl")
```

### Evaluation

The specialized dataset classes provide methods for evaluating model outputs:

```python
# Assuming you have results with model responses
results_df = pd.DataFrame({
    "input": ["..."],
    "answer": ["..."],
    "model_response": ["..."]
})

# Evaluate the results
evaluation_results = await med_notes.evaluate_results(results_df)
accuracy = evaluation_results['metric']
```
